# The hotel payment & billing platform I've designed and built, distilled into a single diagram.

What's inside:
A WinForms desktop client — a deliberate choice for team familiarity and long-term maintainability
Terminal-based and server-direct card authorization, routed by provider
Four PMS integration methods, configurable per hotel
Multiple VAN/PG providers through a common plugin interface
EDI settlement, reconciliation, and hotel billing integration
Role-separated database accounts with restricted access to cardholder data
An MCP interface for AI agents, governed by the same authentication and least-privilege access controls
Signed, independently deployed plugins on a shared codebase for both on-premises and cloud deployments
